## 🚀 Quick Start

1. Clone this repository or open `index.html` directly in any modern browser.
2. No server, no dependencies — just open and learn!

```bash
git clone https://github.com/<your-username>/BluesGuitar.git
cd BluesGuitar
# Open index.html in your browser
```

## 📚 What's Inside

### Scales
- **Minor Pentatonic** — the #1 blues scale (all 5 positions)
- **Major Pentatonic** — bright, country-blues flavor
- **Blues Scale** — adds the signature "blue note"
- **Mixolydian** — the classic blues key scale

### Chords
- **I-IV-V Progressions** — the foundation of blues
- **Dominant 7th Chords** — bluesy voicings
- **Turnarounds** — smooth chord transitions
- **Barre Chords** — movable shapes

### Techniques
- **Bends** — full, half, and quarter bends
- **Slides** — between frets and strings
- **Vibrato** — expressive pitch variation
- **Hammer-Ons & Pull-Offs** — legato techniques
- **String Skipping** — rhythmic articulation

### Riffs & Licks
- Classic 12-bar blues riffs
- Call-and-response patterns
- Lead and rhythm examples

### Fretboard Reference
- Interactive fretboard map
- String and note names
- Position guide
